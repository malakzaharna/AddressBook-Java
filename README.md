# 📞 Address Book System (Java)

A console-based Address Book application built using **Java**. This project demonstrates Object-Oriented Programming (OOP) principles by allowing users to create, search, list, and delete contact details dynamically.

---

## 🌟 Features
- ➕ **Add Contact:** Create new contacts with names, relation types (e.g., Work, Family), and multiple phone numbers.
- 🔍 **Search Contact:** Search for existing contact details by name or phone number.
- 📋 **Display All Contacts:** View all saved contacts in a structured console format.
- 🗑️ **Delete Contact:** Remove contacts from the address book by index or number.

---

## 🛠️ Tech Stack & Concepts
- **Language:** Java
- **IDE:** IntelliJ IDEA
- **Concepts Used:** Object-Oriented Programming (OOP), Custom Classes, Data Structures (`ArrayList`), Loops, Method Overloading / Search Logic.

---

## 🚀 How to Run
1. Clone this repository or download the source code.
2. Open the project in **IntelliJ IDEA** (or any Java IDE).
3. Run `Main.java` to start the console application.
